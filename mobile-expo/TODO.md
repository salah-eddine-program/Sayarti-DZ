# قائمة الإنجاز — سيارتي DZ

- [x] **إنشاء الملف الشخصي والدخول إلى التطبيق:** عند أول تشغيل دون ملف محفوظ تظهر شاشة البدء، ويتيح زر «إنشاء حساب» إدخال الاسم الأول واللقب وعلامة السيارة وطرازها وسنتها ونوع الوقود (ديزل أو بنزين أو غاز) والعداد الحالي؛ كل هذه الحقول مطلوبة، والسنة أربعة أرقام والعداد رقم صحيح غير سالب. عند الحفظ يُخزّن الملف والسيارة على الجهاز، يظهر الاسم في تحية التطبيق، ثم ينتقل المستخدم إلى الرئيسية؛ وعند إعادة فتح التطبيق يُحمّل الملف المحلي ويفتح الرئيسية، مع بقاء «متابعة إلى التطبيق التجريبي» متاحة دون إنشاء ملف. لا يجمع هذا التدفق كلمة مرور ولا ينشئ مصادقة أو مزامنة سحابية، وتظل شاشة تسجيل الدخول تجريبية.
- [x] **الرئيسية والتنقل:** تعرض الرئيسية سيارة المثال Renault Clio 4 موديل 2018، ديزل، 185,200 كم، وملخص الصيانة القادمة والمصاريف الشهرية والوقود والتنبيهات والوثائق؛ ويتيح شريط التنقل الوصول إلى الرئيسية والصيانة والمصاريف والوثائق والإعدادات.
- [x] **الصيانة وسجل السيارة:** يعرض القسم آخر صيانة وسجلها والمواعيد أو المسافات المتبقية، بما فيها تغيير الزيت بعد 1,200 كم وفلتر الهواء بعد 5,000 كم وفحص الإطارات بعد 3,000 كم؛ وتقبل شاشة إضافة الصيانة النوع والتاريخ والعداد والتكلفة والملاحظات وزر فاتورة تجريبيًا، وتحفظ السجل في حالة العرض المحلية.
- [x] **المصاريف:** تعرض مصروفات الشهر 8,450 دج مع تصنيفات الصيانة والوقود وغيرها، وملخص السنة 87,400 دج؛ وتتيح واجهة النموذج إضافة مصروف وتحديث الإجمالي داخل جلسة النموذج.
- [x] **الوقود:** تعرض تعبئة تجريبية تتضمن 2,500 دج و38 لترًا وسعر 65.80 دج/لتر وعداد 184,900 كم مع متوسط استهلاك توضيحي؛ وتوفر واجهة تسجيل تعبئة محلية تضيف قيمتها إلى المصاريف.
- [x] **الوثائق والتنبيهات:** تعرض التأمين والمراقبة التقنية وبطاقة التسجيل وحالاتها وتواريخها؛ وتوضح قرب انتهاء التأمين بعد 23 يومًا، وتعرض تنبيهات الصيانة والوثائق داخل التطبيق من دون إشعارات خلفية.
- [x] **الإعدادات وPremium والسمة:** تتيح الإعدادات تغيير اللغة والسمة، وتحفظهما محليًا؛ وتعرض Premium بسعر تجريبي 500 دج سنويًا من دون بدء دفع حقيقي.
- [x] **العربية والفرنسية والإنجليزية:** يظهر مبدّل اللغة، وتُترجم عناصر الواجهة وبيانات المثال المعروفة؛ تستخدم العربية اتجاه RTL ومحاذاة مناسبة، والفرنسية والإنجليزية اتجاه LTR.
- [x] **الهوية البصرية المخصصة:** اعرض شعار PNG المرفق كاملًا دون قص أو تغيير نسبته في شاشات البداية وإنشاء الحساب وتسجيل الدخول داخل لوح فاتح ينسجم مع خلفية الشعار البيضاء؛ واستخدم علامة مربعة مبسطة متوافقة معه في التطبيق. طبّق أخضر الشعار الغابي والمورق والذهبي والبرتقالي عبر عناصر الهوية، مع إبقاء الأحمر للخطر والأخضر للحالة السليمة، وإتاحة تباين مناسب في السمتين الفاتحة والداكنة.
- [x] **رابط الملف الشخصي الحقيقي:** تعرض الإعدادات وتحفظ الرابط الذي أرسله المستخدم `https://salah-eddine-program.github.io/bt-salahdine.com/`، وتتيح فتحه وتحريره.
- [x] **الموقع التفاعلي للحاسوب:** تتاح نسخة ويب تفاعلية من تطبيق سيارتي DZ على `https://salah-eddine-program.github.io/Sayarti-DZ/sayarti-app/`؛ تدعم العربية والفرنسية والإنجليزية، واتجاه RTL للعربية وLTR للفرنسية والإنجليزية، وتتيح التنقل بين الرئيسية والصيانة والمصاريف والوثائق والإعدادات وتعديل السجلات والتفضيلات محليًا، مع إبقاء صفحة GitHub Pages الحالية عند الجذر سليمة.
